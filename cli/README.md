# TradingAgents CLI 模块

这个重构后的CLI模块提供了更好的可读性和维护性。

## 模块结构

```
cli/
├── __init__.py          # 包初始化文件
├── main.py              # 主入口点 (54行，原来1058行)
├── message_buffer.py    # 消息缓冲区管理 (132行)
├── display.py           # 界面显示管理 (350行)
├── user_interface.py    # 用户交互 (140行)
├── analysis_runner.py   # 分析执行 (280行)
├── utils.py             # 工具函数 (包含extract_content_string)
├── models.py            # 数据模型 (原有)
└── README.md            # 本文档
```

## 重构优势

### 1. **代码可读性显著提升**
- 原始文件1058行 → 拆分为5个专注的模块
- 每个模块职责单一，易于理解
- 类和方法名称清晰，功能明确

### 2. **维护性增强**
- 模块化设计，修改一个功能只需关注对应模块
- 减少了代码耦合，降低了修改风险
- 更容易进行单元测试

### 3. **可扩展性改善**
- 新功能可以独立添加到相应模块
- 插件式架构，支持功能模块的独立开发
- 接口清晰，便于团队协作

## 核心组件

### MessageBuffer (消息缓冲区)
- 管理消息、工具调用和报告状态
- 追踪代理执行状态
- 维护报告部分的完整性

### DisplayManager (显示管理器)
- 负责所有UI界面的渲染
- 管理进度显示、消息面板、分析面板
- 处理完整报告的展示

### UserInterface (用户界面)
- 处理所有用户输入交互
- 引导用户完成配置选择
- 验证用户输入的有效性

### AnalysisRunner (分析运行器)
- 执行分析流程的核心逻辑
- 管理LangGraph流式处理
- 协调各个组件的工作

## 使用方法

```python
from cli.main import app

if __name__ == "__main__":
    app()
```

或者命令行：
```bash
python cli/main.py analyze
```

## 设计原则

1. **单一职责原则**: 每个模块专注于一个核心功能
2. **开闭原则**: 对扩展开放，对修改关闭
3. **依赖注入**: 通过构造函数注入依赖，提高测试性
4. **接口隔离**: 清晰的模块接口，减少不必要的依赖
